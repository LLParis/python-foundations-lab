## How I practice

Understand the requirement → attempt it → predict behavior → run when appropriate
→ debug → explain → solve a changed requirement → revisit later.

The daily tutor is GPT web. I write code in VS Code. The local Learning Arena
extension preserves attempts and prepares exact code packets for feedback. It
makes no model calls, writes no solutions, and assigns no readiness score.
Assistance is recorded for each submitted attempt; successful execution alone
does not establish correctness or mastery.

## Open the learning workspace

On this workstation, double-click **Open Learning Arena.cmd**. It opens the
separate **Learning Arena** VS Code profile with the current prompt beside my code.

- **Write current attempt**: continue in a real Python file.
- **Copy attempt for tutor**: save a dated copy, then paste the packet into GPT web.
- **Run when ready / Debug current attempt**: execute and inspect the program.
- **Save local checkpoint**: commit real work locally; pushing to GitHub is explicit.
- **New exercise from clipboard**: bring in the next tutor-assigned task.

[Daily workflow](docs/WORKFLOW.md) · [GitHub connection](docs/GITHUB.md) ·
[Tutor handoff](docs/TUTOR_HANDOFF.md)

For another Windows machine with VS Code, Git, and uv installed, run
`powershell -ExecutionPolicy Bypass -File tools/install.ps1` once, then open the
launcher. The workspace uses Python 3.14; the extension has no npm dependencies.

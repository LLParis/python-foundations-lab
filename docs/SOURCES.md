# Setup sources — checked September 19, 2026

- [VS Code Python](https://code.visualstudio.com/docs/languages/python): native
  Python execution, environment selection, and debugging.
- [VS Code debugger](https://code.visualstudio.com/docs/python/debugging):
  `debugpy` launch configurations and variable inspection.
- [VS Code profiles and CLI](https://code.visualstudio.com/docs/configure/command-line):
  a named empty profile and per-profile extension installation.
- [Disable built-in AI](https://code.visualstudio.com/docs/setup/copilot):
  workspace-scoped `chat.disableAIFeatures`.
- [Tree View API](https://code.visualstudio.com/api/extension-guides/tree-view):
  native sidebar commands, without another web server or AI subscription.
- [VS Code API](https://code.visualstudio.com/api/references/vscode-api): clipboard,
  commands, editor, output channel, and debugger integration.
- [ChatGPT projects](https://learn.chatgpt.com/docs/projects?surface=web) and
  [plugins](https://learn.chatgpt.com/docs/plugins): shared context and connected
  services. These do not establish live synchronization of unsaved local code.
- [GitHub contributions](https://docs.github.com/en/account-and-profile/concepts/contributions-on-your-profile):
  pinned work and public/private contribution visibility.

Community implementation signal: reports in the OpenAI developer forum describe
GitHub repository indexing and connection delays. These are anecdotal and not
service guarantees. The clipboard packet keeps same-attempt tutoring independent
of repository retrieval latency. No unverified employer claims were used to set
the learning baseline.

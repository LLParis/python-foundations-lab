# Selected work

This index is reserved for work substantial enough to inspect as a project or
technical investigation. There are no completed showcase projects claimed yet.

The active [learning exercises](../exercises/0001-find-index/prompt.md) establish
the current starting point. As completed work earns a place here, each entry will
link to its code, reproducible use, reasoning, validation, limitations, and clear
authorship. [This template](TEMPLATE.md) defines the information to preserve.

Potential future work should arise from the curriculum and a useful problem;
this index is not a commitment to launch several projects before the fundamentals.
